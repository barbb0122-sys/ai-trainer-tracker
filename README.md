# AI Trainer Pay & Hours Tracker
Created by Barbara Hood

Live site: https://ai-trainer-tracker.vercel.app/

Helps independent AI trainers track contracts, payments, and weekly income goals across projects.

- Contracts: platform, project, hourly rate, dates, Active/Paused/Completed
- Payments: expected vs received, tax set-aside %, set-aside + remaining math, one-click mark-received
- Weekly goal: gross goal, log hours by date/project, earnings = hours × rate, hours-still-needed forecast
- Full-width progress bar with 25/50/75% ticks. Cash received shown separately.
- Try sample data button with 4 fictional projects for instant demo. Saved in browser (localStorage).

Built with v0, Next.js, deployed on Vercel.
